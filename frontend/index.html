¿Qué es Karplus-Strong?

El algoritmo Karplus-Strong es un método simple y elegante para sintetizar instrumentos de cuerda pulsada como guitarras, arpas y pianos. Desarrollado en 1983, utiliza un breve estallido de ruido filtrado a través de una línea de retardo para crear sonidos de cuerdas sorprendentemente realistas.

Esta aplicación web trae el algoritmo a la vida en tu navegador usando la Web Audio API, permitiéndote aprender la teoría y experimentar creando música.
